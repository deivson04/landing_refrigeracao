# ❄️ Site de Refrigeração Profissional

Site institucional responsivo desenvolvido em **HTML, CSS e JavaScript**, voltado para profissionais de **refrigeração e ar-condicionado**, com foco em **SEO local**, **contato rápido via WhatsApp** e **boa experiência em dispositivos móveis**.

🔗 **Site online:**  
https://SEU_USUARIO.github.io/site-refrigeracao/

---

## 📌 Funcionalidades

- ✅ Layout profissional e responsivo
- ✅ Design adaptado para celular, tablet e desktop
- ✅ Botão flutuante do WhatsApp
- ✅ Animações leves ao rolar a página
- ✅ Site rápido e leve
